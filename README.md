# Portal Monitoring KKMP Kota Ternate — Frontend

Frontend statis (HTML/CSS/JS) untuk GitHub Pages. Data diambil dari backend Google Apps Script (REST API).

- `index.html` — struktur halaman
- `css/style.css` — tampilan
- `js/config.js` — **isi `GAS_URL`** dengan URL `/exec` Apps Script
- `js/app.js` — logika aplikasi (memanggil backend via `fetch()`)
- `img/logo.png` — logo

Panduan lengkap: lihat `PANDUAN-INSTALASI.md`.
